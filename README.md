# SimpleGames

## Sobre este repositorio
Este repositorio es creado meramente para familiarizarce con el lenguje de programacion en C# a traves de juegos simples por consola.

## Detalles
- Uso de factory method para ir agredango nuevos juegos.
- Singleton para listar los  juegos e instanciar el seleccionado con el creador respecvitvo.
- El programa principal toma le interfaz de juego IGame.
